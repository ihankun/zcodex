# Desktop 辅助窗口定位

## 背景

桌面端的应用自有弹窗（关于、资源管理器、更新状态、强制升级提示、Endpoint 输入窗）此前都按 Electron 默认放置：未显式给出 `x` / `y` 时落在显示器居中位置，`win.center()` 也按窗口当前所在显示器居中。用户把应用主窗口拖到屏幕右下角后，这些弹窗仍然出现在屏幕正中间，和触发它们的应用窗口脱节。

本规格把辅助窗口的初始位置改为**以应用主窗口为锚点居中**，并保证窗口始终落在锚点所在显示器的可用工作区内。

## 产品规则

- 辅助窗口打开时，以应用主窗口 `getBounds()` 的中心对齐辅助窗口 `getBounds()` 的中心。
- 锚点所在显示器决定可放置区域：使用 `screen.getDisplayMatching(anchorBounds).workArea`，不跨显示器居中。
- 居中结果必须收敛到工作区：窗口比工作区小且居中位置越界时，贴工作区边缘；窗口比工作区大时，从工作区左上角开始放置。
- 无法确定应用主窗口时（例如强制升级在创建主窗口之前阻断启动、托盘入口在无窗口时触发），保留系统默认放置（显示器居中），不阻塞弹窗创建。
- 已经打开的辅助窗口不跟随主窗口移动；单例窗口（资源管理器、更新状态）在已打开时只聚焦，不重新定位。关闭后再次打开时按当时的主窗口位置重新居中。
- macOS 上以 sheet 形式贴附在父窗口的 modal 子窗口由系统管理位置，主进程不强行 `setPosition`；其视觉归属已是父窗口，无需屏幕居中修正。

## 锚点选择

锚点由 `packages/desktop/src/main/desktopWindowSize.ts` 的辅助窗口定位段落统一解析，顺序如下：

1. 调用方显式传入的窗口（例如命令来自某个主窗口的 IPC / 原生菜单）。
2. 当前聚焦的应用主窗口。
3. 最近一次聚焦过的应用主窗口。
4. 仍存活的应用主窗口。
5. 都没有时返回 `undefined`，调用方回退到系统默认放置。

应用主窗口注册表由 `desktopWindowLifecycle` 在 `createBrowserWindow` 之后登记（`registerDesktopApplicationWindow`），窗口 `closed` 时自动移除。资源管理器、关于、更新提示等辅助窗口不登记，因此不会被当成下一次弹窗的锚点。

## 适用范围

| 窗口 / 交互 | 入口 | 定位方式 |
| --- | --- | --- |
| 关于 | 原生菜单、问号帮助菜单、托盘 | 居中于锚点；有显式父窗口时保持 parent/modal 关系 |
| 资源管理器 | 原生菜单、问号帮助菜单 | 触发时居中于锚点 |
| 更新状态窗口 | 帮助菜单、更新事件 | 首次显示前居中于锚点；失败时保留 `win.center()` |
| 强制升级提示 | 启动门禁 | 有主窗口时居中于锚点；无主窗口（正常路径）保持屏幕居中 |
| Endpoint 输入窗（开发态） | 原生菜单 | 居中于显式父窗口或锚点 |
| 原生文件 / 目录选择器 | 设置页、工作区操作 | `dialog.showOpenDialog(parentWindow, ...)`，owner 设为发起调用的窗口 |

不在本规格内：

- Windows CUA 操作指示窗（按光标位置定位）。
- 隐藏的辅助 `BrowserWindow`（localStorage 导入窗、WebM 录制窗）。
- 外部浏览器链接（更新说明、反馈表单、社区）。
- 已打开辅助窗口的实时跟随移动。

## 状态与所有权

- 主窗口注册表由 main 进程持有，唯一写入点是 `desktopWindowLifecycle` 的窗口创建 / 关闭生命周期。
- 定位是打开时的一次性展示决策，不写入 `setting.json`，不参与主窗口尺寸/位置持久化（见 `docs/desktop/main-window-size.md`）。
- 原生选择器只把调用窗口作为 owner 传给 Electron，不改变选择结果的返回协议。

## 验收

E2E：

- `packages/desktop/test/e2e/help-menu-about.test.ts`：关于窗口可见后，其窗口中心与主窗口中心水平偏移 ≤ 2 DIP；Windows / Linux 同时断言垂直偏移 ≤ 2 DIP（macOS sheet 由系统定位，只断言水平）。
- `packages/desktop/test/e2e/resource-manager-storage.test.ts`：打开资源管理器后断言同样的中心偏移。

手动场景（Windows，双屏或单屏均可）：

1. 把主窗口拖到屏幕右下角，`Win+↑` 之外保持普通尺寸。
2. 从问号菜单打开「资源管理器」：窗口出现在主窗口中间，而不是屏幕正中。
3. 关闭后把主窗口拖到另一块显示器，再打开：窗口跟随到主窗口所在显示器。
4. 打开「关于」：同样居中于主窗口；拖动主窗口后再次打开，位置随主窗口更新。
5. 主窗口最大化：弹窗居中于最大化后的窗口（等价于屏幕居中）。
